# CommerceLake

A local-first e-commerce data engineering lakehouse.

## Objectives

- Build reproducible ingestion pipelines.
- Implement Bronze, Silver, and Gold data layers.
- Process data with Apache Spark and PySpark.
- Store analytical tables using Delta Lake.
- Validate data contracts and business metrics.
- Automate testing and pipeline execution.
- Document architecture, operations, and recovery procedures.

## Development

Use Python 3.12 in an isolated virtual environment.

Cloud resources are not required for local development.

## Data policy

Use synthetic or appropriately licensed public datasets.
Never commit credentials, secrets, or sensitive customer data.
